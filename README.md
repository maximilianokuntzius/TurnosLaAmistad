# Turnos La Amistad

Sistema de gestión, planificación y rotación inteligente de turnos de cajas para Supermercados La Amistad.

## Características
- **Planificación interactiva**: Asignación de cajeros mediante arrastrar y soltar (Drag & Drop).
- **Sincronización en la nube**: Conexión en tiempo real multidispositivo vía Firebase Realtime Database.
- **Vista Semanal Completa**: Calendario de lunes a domingo para control de la semana en un solo vistazo.
- **Notas y observaciones diarias**: Notas libres integradas en la tabla, el Excel, la imagen y el reporte de WhatsApp.
- **Generador de WhatsApp**: Copiado con formato de negritas y emojis listo para enviar al grupo.
- **Exportación avanzada**: Planillas Excel (.xlsx) estructuradas por persona y por semana, además de imágenes de alta resolución.
- **Gestión de ausencias**: Control de francos, licencias médicas, días de estudio y vacaciones con balance de horas extras.
